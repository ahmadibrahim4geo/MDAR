## Summary
Diagnosed and resolved the blank white screen issue reported when visiting `https://ahmadibrahim4geo.github.io/MDAR/`. The repository had GitHub Pages configured in `legacy` mode (`source: {branch: "main", path: "/"}`), which caused GitHub's built-in Jekyll runner to deploy the raw, uncompiled root `index.html` containing `<script type="module" src="/src/main.tsx"></script>`. Browsers could not execute the TypeScript source, resulting in a blank page. Resolved by updating GitHub Pages `build_type` to `workflow` via the GitHub REST API, updating `.github/workflows/deploy.yml` with proper base path extraction, updating `vite.config.ts`, and adding `public/.nojekyll` and `public/404.html`.

## Key Deliverables & Evidence
1. **Root Cause Analysis & Diagnostic Verification**:
   - `GET /repos/ahmadibrahim4geo/MDAR/pages` returned `"build_type": "legacy"`.
   - Live HTTP request to `https://ahmadibrahim4geo.github.io/MDAR/` served raw uncompiled root `index.html` with `<script type="module" src="/src/main.tsx"></script>`.
2. **GitHub API Configuration Fix**:
   - Executed `PUT /repos/ahmadibrahim4geo/MDAR/pages` with `{"build_type": "workflow"}` (HTTP 204 Success).
   - Verified updated settings: `"build_type": "workflow"`.
3. **Workflow & Build Pipeline Updates**:
   - Added `workflow_dispatch` trigger to `.github/workflows/deploy.yml`.
   - Placed `actions/configure-pages@v4` ahead of `npm run build` to inject `VITE_BASE_PATH: ${{ steps.pages.outputs.base_path }}/`.
   - Updated `vite.config.ts` to respect `process.env.VITE_BASE_PATH || './'`.
   - Created `public/.nojekyll` to disable Jekyll static file filtering.
   - Created `public/404.html` for client-side single-page app redirection.
4. **Verification**:
   - `npm.cmd run lint`: 0 errors.
   - `npm.cmd run build`: 0 errors, compiled with `/MDAR/` base path.
